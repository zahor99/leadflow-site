Proposal walkthrough

Modular AI operating system for marine operations

AI Engineer | LLM Systems, Agents & Workflow Automation

In short

A phased architecture proposal for a marine and offshore AI platform — knowledge base first, then specialised agents for Tender, Procurement, HR, and COO oversight, with human-in-the-loop approval gates throughout. Phase 1 delivers a working knowledge base and two pilot agents the team can use immediately. Built on Postgres/pgvector, LangGraph, and n8n.

Architecture I'd propose

  • Ingestion layer — Emails, Tender docs, Vessel specs, Meetings (Whisper)
  • Knowledge core — Postgres/pgvector, OCR + metadata, Permission-aware retrieval
  • Agent team — Marine, Tender, Procurement, BD, HR, COO assistant
  • Workflow backbone — n8n pipelines, Approval gates, Audit log
  • User surfaces — Web UI, Telegram approvals, Task manager
Assumes: Assumes documents are primarily PDFs/Office formats — if Confluence or SharePoint, ingestion connector changes, nothing else does · Assumes approval gates via web UI or Telegram — channel is configurable · Assumes Microsoft Teams for meetings — Whisper transcription applies equally to Zoom or Google Meet — tell me where I'm wrong and the design adapts.

Plan

  • Phase 1 - Foundation (Weeks 1-4) — Live knowledge base + Tender & Marine agents + email ingestion
  • Phase 2 - Agent expansion (Weeks 5-10) — Procurement, BD, HR agents + workflow automation + approval gates
  • Phase 3 - Intelligence layer (Weeks 11+) — COO dashboard, business-rules engine, voice, learning system

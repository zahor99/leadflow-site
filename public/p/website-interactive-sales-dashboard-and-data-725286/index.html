Website + Interactive Sales Dashboard and Database Integration with Custom AI Chatbot

In short

A branded, password-protected sales dashboard built in Next.js with live Google Sheets integration, interactive charts, and an AI chatbot that answers questions against your live menu and revenue data. The project runs 8–14 weeks across three phases, with a working dashboard in your hands after the first four to six weeks. Ongoing costs estimate $50–150/month for hosting and AI API usage.

Architecture I'd propose

  • Google Sheets — source of record
  • Postgres/Supabase — structured data layer
  • Next.js dashboard — Recharts, auth, filters
  • Context builder — injects live data at query time
  • Claude / GPT-4o — answers against live figures
Assumes: Assumes Google Sheets is the primary data source, not a POS API · Assumes password-protected route is sufficient auth, not full user management · Assumes chatbot answers from injected context, not a trained fine-tuned model — tell me where I'm wrong and the design adapts.

Plan

  • Phase 1 - Dashboard (Weeks 1–6) — Live dashboard with Sheets sync and all charts
  • Phase 2 - Chatbot (Weeks 7–9) — AI chatbot reading live dashboard data
  • Phase 3 - Deploy (Weeks 10–14) — Hosted, monitored, handover docs

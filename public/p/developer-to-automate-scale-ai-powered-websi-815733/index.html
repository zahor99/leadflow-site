Developer to Automate & Scale AI-Powered Website | Lovable + Supabase

In short

Your Lovable review site currently takes 20–30 minutes per page to launch manually. This project extracts your existing design into a data-driven React component backed by Supabase, adds a simple admin UI for draft-to-publish workflow, and wires in OpenAI structured outputs so AI-generated content populates pages automatically — architecture built for hundreds of thousands of rows from day one.

Architecture I'd propose

  • Supabase Schema — pages + products + assets
  • OpenAI Structured — JSON schema → validated insert
  • Admin UI — draft → preview → publish
  • Next.js Dynamic Route — slug-based, ISR/SSG
  • Supabase Storage CDN — images served at edge
Assumes: Assumes existing Lovable design can be extracted as a React component without a visual redesign · Assumes ISR is acceptable for SEO — if fully static SSG is required, phase 2 build step changes · Assumes OpenAI function-calling schema is defined once and reused for bulk import — tell me where I'm wrong and the design adapts.

Plan

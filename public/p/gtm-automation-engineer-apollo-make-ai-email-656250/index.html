Apollo + Make + AI nurture system for 150 PT leads

GTM Automation Engineer (Apollo + Make + AI + Email Automation)

In short

Gergely would build a complete Make.com pipeline that enriches your 150 warm PT leads via Apollo, scores them on a weighted rubric, generates one AI-personalized sentence per lead, triggers a 3-email sequence from Gmail/Outlook, and halts automatically on any reply — all tracked in a Google Sheets dashboard. No new tools, no cold-outreach framing: every email reads like a human follow-up from someone who already knows their clinic.

Architecture I'd propose

  • Google Sheets — 150 leads import trigger
  • Apollo Enrichment — clinic size, title, site
  • Claude Scoring — title × 0.4 / size × 0.3 / pain × 0.3
  • AI Personalization — one-sentence insert per lead
  • 3-Email Sequence — Gmail / Outlook trigger
  • Reply Webhook — halts thread on any response
Assumes: Assumes leads are in an existing Google Sheet with at minimum name, email, and clinic name columns · Assumes Apollo API access is available or client can provision it · Assumes Gmail or Outlook OAuth credentials can be connected to Make.com · Assumes provided email copy slots one AI-personalized sentence as a variable — tell me where I'm wrong and the design adapts.

Plan

  • Phase 2 - Reporting & hardening (Days 4–5) — Sheets dashboard + error handlers + retry logic on every API call

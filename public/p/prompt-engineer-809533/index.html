Gergely proposes a multi-step prompt engineering pipeline that converts complex SEO content briefs — keyword frequencies, spacing rules, tone, headings — into reliable, validated LLM outputs. Architecture I'd propose

  • System Prompt Stack — Structural / keyword / tone
  • Outline → Draft — Section-by-section generation
  • Keyword Audit — Regex: freq + spacing checks
  • Final Edit Pass — Tone, flow, factual grounding
  • Eval & Regression — Rubric scores, version log

AI Automation Build for Bid / Estimating Team

In short

A three-stage AI automation covering opportunity logging, tender scope review, and draft BoQ generation — connecting Dropbox, Monday.com, and Claude via n8n. Each workflow is API-native, delivers a concrete output your estimators can use immediately, and is phased so you validate before committing to the next. Built on a self-hosted n8n stack with pgvector for historical project similarity, at $75/hr with a full breakdown per workflow.

Architecture I'd propose

  • Trigger — Dropbox webhook / Outlook
  • n8n Orchestrator — fetch, route, retry logic
  • Claude API — extract, analyse, structure
  • pgvector Store — historical project similarity
  • Monday.com — GraphQL API — log & notify
  • Dropbox Output — Word / Excel saved to folder
Assumes: Tender docs arrive as PDFs via Outlook or saved directly to Dropbox · Historical project archive can be embedded into pgvector at project start · Monday.com status field 'bid confirmed' is the agreed Workflow 2 trigger · A standard BoQ Excel template and cost-code list will be provided — tell me where I'm wrong and the design adapts.

Plan

  • Phase 1 — Opportunity Logging (Weeks 1–3) — Live Workflow 1: auto-log + acknowledgement email
  • Phase 2 — Scope Review (Weeks 4–7) — Structured scope/risk/RFI doc in Dropbox + Monday summary
  • Phase 3 — Draft BoQ (Weeks 8–11) — Auto-populated BoQ Excel saved to project folder
